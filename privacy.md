# Privacy policy

Home Server Backups is used by its owner to manage personal backups. It uses Google’s `drive.file` permission to upload, read, verify, and remove backup files it has access to. Backup files are stored in the owner’s Google Drive. Authorization tokens are stored in the rclone configuration on the owner’s server.

The backup setup does not sell or share backup files or Google user data with other parties. Its use of data received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including its Limited Use requirements.

The owner can delete backups in Google Drive and revoke authorization in [Google Account connections](https://myaccount.google.com/connections). This public information page does not accept sign-ins, backup files, or credentials. GitHub hosts the page under its [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
